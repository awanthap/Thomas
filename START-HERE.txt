THOMAS & DINITHI — OUR LOVE STORY
=================================

This folder contains the complete website source and all eight optimized photos.

QUICK START
1. Install Node.js 20 or newer.
2. Open a terminal inside this folder.
3. Run: npm install
4. Run: npm run dev
5. Open the local address shown in the terminal.

MAIN FILES
- app/page.tsx       Complete story, wording, photos, and interactions
- app/globals.css    Full romantic design and phone/desktop styling
- app/layout.tsx     Page title and social-sharing information
- public/memories/   All eight photographs
- public/og.png      Social-sharing cover

THOMAS & DINITHI — GITHUB PAGES READY
=====================================

IMPORTANT:
Upload the CONTENTS of this folder directly to the root of the GitHub repository.
Do not upload only this ZIP file.

FILES THAT MUST APPEAR IN THE REPOSITORY ROOT:
- index.html
- style.css
- script.js
- .nojekyll
- assets (folder)

GITHUB SETTINGS:
1. Open the Thomas repository.
2. Open Settings.
3. Choose Pages in the left sidebar.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch: main.
6. Choose folder: /(root).
7. Click Save.
8. Wait 2–10 minutes.

FINAL LINK:
https://awanthap.github.io/Thomas/

If the old plain page remains, press Ctrl + F5 once after the new deployment
turns green.
